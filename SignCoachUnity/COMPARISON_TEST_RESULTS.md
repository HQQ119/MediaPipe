# 第四阶段实际测试报告

2026-11-09，Unity 2022.3.62f3c1、Windows64 Mono。所有算法均在当前 Unity 项目实际编译运行。
本报告区分算法正确性、数据接口联调与尚未验证的真人手语评价。

## 修改与新增

新增独立目录 `Assets/Scripts/Comparison/`：

- ComparisonTypes.cs：参数、质量、数据类型、特征和结果结构。
- HandFeatureExtractor.cs：关节角、指尖距离、相对点、掌中心轨迹、相对尺度、掌方向及分组距离。
- SequencePreparer.cs：标签分离、歧义处理、短缺失插值、长缺失质量标记和独立归一化数组。
- DtwSolver.cs：成本矩阵、累计矩阵、单调最优路径、路径长度归一化、可配置对角窗口。
- SequenceComparer.cs：复用历史文件读取，组合质量、DTW、相似度、分组差异和时间区间。
- SequenceComparisonPanel.cs：后台计算，来源/质量/时长/比例、相似度、时间轴、矩阵路径、差异片段及新文件报告导出。

新增 `Assets/Editor/ComparisonTests.cs`，修改 BuildAndVerify 调用；在 SignCoachDebug 接入比较面板，RecordingPanel 打开比较时暂停显示其控件。
VerificationCapture 仅增加显式验收模式的比较入口和结果记录。原追踪与录制逻辑不重写。
新增 COMPARISON_GUIDE.md、本报告并更新 README；生成对应 .meta、场景和 Windows Player。

未修改 Python MediaPipe/TCP；未改 HandFrame、HandSkeleton、RecordingStore、ActionRecorder；原始 JSONL 与 metadata 不变。
文件指纹核对另存于 Python `output/stage4/unchanged_inputs_and_protocol.json`。
